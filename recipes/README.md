# Recipes

Composed solutions that combine components, effects, motion, tokens, or layouts
for a recognizable UI problem.

Recipes should reference their underlying patterns instead of duplicating them.

`production-recipes.json` is the machine-readable authority. Each recipe lists
existing catalog package IDs, their roles, composition guidance, and rejection
conditions. Recipes contain no copied CSS and do not override project-local
components or design tokens.

Current recipes:

- clean dashboard card
- primary action button
- knowledge-base content page
- hero section
- loading state
- form field
- metric card
- empty state
- validation feedback
- responsive media card
