# Tokens

Guidance and framework-neutral primitives for spacing, typography, radii,
shadows, aspect ratios, and easings.

These are reference primitives. A target project's own design tokens take
precedence.

Each family is a self-contained package with a README, scoped `tokens.css`, and
standalone demo. The current Open Props foundation deliberately excludes color
palettes, gradients, resets, components, JavaScript, assets, fonts, and themes.
